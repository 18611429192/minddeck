# MindDeck V9.5.1 RC

这是 V9.5 RC 的演示交互修复版。

## 演示

- 全屏演示时隐藏编辑工具栏和编辑侧栏。
- 键盘：
  - `←` / `↑` / `PageUp`：上一页
  - `→` / `↓` / `PageDown` / `Space`：下一页
  - `T`：显示 / 隐藏目录
- 鼠标滚轮：
  - 向上：上一页
  - 向下：下一页
  - 420ms 节流，避免触控板一次滚动连续跳页
  - 鼠标位于目录、视频、输入控件时不触发翻页
- 手机继续支持左右滑动。
- Portable 独立演示和融合 HTML 同步支持 ↑ / ↓ 和滚轮。
- 融合 HTML 在浏览器 fullscreen 时隐藏顶部模式工具栏。

## 编辑侧栏

- 桌面节点详情、演示顺序、导出设置面板可以收起。
- 收起后右侧出现窄恢复把手。
- 节点详情被主动收起后，点击其它节点不会强制把它重新弹出来。
- 具体页面编辑属性栏同样支持收起 / 恢复。
- 手机继续使用底部抽屉，不显示桌面恢复把手。

## 建议检查

1. 进入全屏演示，确认没有顶部编辑按钮。
2. 分别测试 ↑ ↓ ← →、PageUp、PageDown、Space。
3. 快速滚动鼠标滚轮，确认一次只翻一页。
4. 在目录内滚动，确认目录滚动而页面不翻。
5. 收起节点编辑侧栏，切换节点，再手动恢复。
6. 收起页面属性栏，再恢复。
7. 导出独立演示 HTML 和融合 HTML，重复 1～4。
