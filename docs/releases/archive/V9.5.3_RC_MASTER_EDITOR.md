# MindDeck V9.5.3 RC

## 母版编辑重做

V9.5.2 仍然把母版当成“特殊设置界面”，这和普通页面编辑的心智模型不一致。

V9.5.3 改为：

- 母版和普通页面使用同一个 1600×900 编辑器
- 同一个插入工具栏
- 同一套文字 / 图片 / 视频 / 形状
- 同一套选中、拖动、四角缩放
- 同一套双击文字编辑
- 同一套多选、对齐、复制、删除和图层
- 同一个右侧元素属性栏
- 点击画布空白处只取消选择，不再弹出特殊“母版背景”界面

唯一的区别：

- 普通页面写入 `node.slideElements`
- 母版写入 `data.master.elements`

## 母版设置

背景颜色、背景图片、目录显示、目录位置、默认动画不再自动占住右侧栏。

桌面：

- 进入母版
- 点击顶部 `母版设置`

手机：

- 进入母版
- 没有选中元素时点击底部 `属性`

即可打开母版全局设置。

## 建议验收

1. 打开母版
2. `+ 文字`
3. 拖动文字
4. 四角缩放
5. 双击直接改文字
6. `+ 图片`
7. `+ 矩形`
8. 多选两个元素并对齐
9. 复制、删除、调整图层
10. 点击空白，属性栏关闭
11. 点 `母版设置`，修改背景颜色
12. 返回当前页，确认所有母版元素仍显示
13. 新建/切换其他节点页面，确认母版元素仍显示
