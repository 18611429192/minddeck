# 产品化路线

## V9.0 — 统一运行时基础
- 保持完整稳定版可直接运行。
- 开始抽离共享 Core。
- 固化 schema/runtime 版本。

## V9.1 — 自动回归与自检
- 建立固定分辨率检查矩阵。
- 自动生成纯导图/演示/融合 HTML 并重新打开检查。
- 增加项目健康检查和导出前自检。

## V9.2 — 交互收敛
- 固定桌面入口分组。
- 固定手机底栏模型。
- 删除重复入口和行为差异。

## V9.3 — 视觉系统
- 节点、面板、目录、工具栏统一 token。
- 明亮/深色/商务/极简少量正式主题。

## V9.4 — 大项目性能与恢复
- 10 / 50 / 100+ 节点测试。
- 图片视频资源策略。
- 自动恢复和异常项目保护。

## V9.5 — Release Candidate
- 冻结功能。
- 只修阻断性问题。
- 发布 Demo 和首次使用引导。

## 1.0
