# MindDeck V9.5 Release Candidate 发布清单

## 功能冻结
V9.5 RC 之后不再新增编辑能力。进入 1.0 前只接受：
- 数据丢失
- 无法导出/导入
- 无法进入演示
- 页面比例错误
- 主流分辨率无法操作
- 明显性能退化
- 安全或兼容阻断

## 每次候选发布必须完成
- [ ] `npm run release:check` 全绿
- [ ] 应用内项目自检无 fail
- [ ] JSON 导出 + 重新导入
- [ ] `.minddeck` 导出 + 重新导入
- [ ] 纯导图 HTML 打开并重排/折叠
- [ ] 演示 HTML 目录开关、节点折叠、翻页
- [ ] 融合 HTML 两种模式切换
- [ ] 1920×1080 / 1366×768 / 1024×768
- [ ] 390×844 / 844×390 / 360×800
- [ ] 至少一个 50+ 节点真实项目
- [ ] 至少一个包含图片和视频的项目

## 1.0 发布原则
宁可少一个功能，也不能让用户在正式汇报时遇到不可恢复的问题。
